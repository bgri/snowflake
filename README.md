# Parametric Snowflake Maker
<img width="3424" height="2028" alt="Screenshot" src="https://github.com/user-attachments/assets/1c670500-1ddd-4022-af73-4dcc980c2fb2" />

A zero-dependency standalone single-file web application built with **Three.js** and **Tailwind CSS** that generates intricate, mathematically harmonic 3D parametric snowflakes in real time.

## Features

- **Parametric Generation Engine:** Customize branches, symmetry, complexity, depth, and harmonic aesthetics on the fly.
- **Interactive 3D Viewport:** Smooth orbit, pan, and zoom controls powered by Three.js.
- **Zero Installation & Self-Contained:** Packaged entirely into a single HTML file containing all assets, shaders, and styling. No build tools, package managers, or server requirements.
- **Responsive & Lightweight:** Runs smoothly across modern desktop and mobile browsers.

---

## Getting Started & Local Use

Because this project is delivered as a single self-contained HTML file (`snowflake_maker.html`), using it locally is effortless:

1. **Download:** Click on `snowflake_maker.html` in this repository and download the raw file (or clone the repository).
2. **Run:** Double-click or open `snowflake_maker.html` in any modern web browser (Chrome, Safari, Firefox, Edge).
3. **Explore:** Adjust parameters, experiment with harmonic aesthetics, and enjoy exploring complex 3D fractal snowflake geometries instantly offline!
